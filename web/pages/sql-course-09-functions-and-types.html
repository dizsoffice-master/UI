Lesson 9: Transform values in a SELECT

Functions operate on values per row unless used as aggregates or window functions. Cast explicitly when input formats are known, and avoid turning dates or numbers into text until presentation.

SELECT customer_id,
       COALESCE(NULLIF(TRIM(phone), ''), 'Not provided') AS phone_label,
       DATE_TRUNC('month', created_at) AS signup_month
FROM customers;

NULL-safe expressions

NULL means unknown or missing, not an empty string or zero. Arithmetic with NULL usually returns NULL. Use COALESCE only when the fallback is semantically correct. Divide safely with NULLIF, then decide whether a missing ratio should remain NULL or be displayed another way.
