Lesson 8: Model the rules in the schema

Choose types that represent the domain. Use numeric types for exact money, timestamps with time zones for global events, and constraints for invariants that every writer must obey.

CREATE TABLE customers (
  customer_id bigint GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
  email text NOT NULL UNIQUE,
  created_at timestamptz NOT NULL DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE orders (
  order_id bigint GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
  customer_id bigint NOT NULL REFERENCES customers(customer_id),
  total numeric(12,2) NOT NULL CHECK (total >= 0)
);

Choose types and relationships

Use numeric(p,s) for exact decimal quantities such as money, date for calendar dates, timestamptz for instants, and jsonb for flexible PostgreSQL JSON. Normalize repeated entities and define delete/update behavior on foreign keys deliberately.
