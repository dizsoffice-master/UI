Lesson 9: One formula can return many cells

In current Microsoft 365 and Excel for the web, a dynamic-array formula spills results into adjacent cells. Keep the spill area empty. An occupied cell causes #SPILL!. Older perpetual editions may not include all functions on this page.

If A2:A6 contains names and B2:B6 contains regions, =SORT(UNIQUE(A2:A6)) returns a sorted list of distinct names.

LET and LAMBDA patterns

LET makes a long formula easier to read by naming values once. LAMBDA can be saved in Name Manager to create a workbook function. Start with a small test range, confirm spill dimensions, and document any custom names so other users can maintain the workbook.
