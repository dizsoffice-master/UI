Lesson 5: Match a key and return its value

Suppose A2:A5 contains product IDs P-10, P-11, P-12, P-13, B2:B5 contains prices 12, 18, 9, 25, and E2 contains P-12. Exact match is usually the right choice for IDs.

Modern exact lookup: =XLOOKUP(E2,A2:A5,B2:B5,"Not found") returns 9.

Choose a lookup pattern

  • Use XLOOKUP for new workbooks when the target Excel version supports it.
  • Use INDEX/MATCH when you need broad compatibility or independent row and column matching.
  • Use VLOOKUP with FALSE for exact matching in older workbooks; the lookup column must be first.
  • Wrap a not-found case with an explicit message; avoid approximate matches on unsorted IDs.
