What to know about meta tags and document metadata in HTML

Metadata impacts SEO, page previews, and how the browser interprets the document. Title, description, and charset matter. This chapter explains the concept, demonstrates a practical example, and gives you a guided exercise.

How to use meta tags and document metadata in HTML

Choose elements for their meaning, nest them in a clear document structure, and use descriptive attributes. Check that links and forms work with a keyboard and that images have useful alternative text.

Example: meta tags and document metadata in HTML

Use this example as a starting point. Identify the part that controls the result, then adapt it to your own page or project.

<meta charset="UTF-8">
<meta name="description" content="...">

Common questions about meta tags and document metadata

When should I use meta tags and document metadata?

Use this technique when it expresses the structure, styling, or behavior your page needs. Keep the implementation focused and test it with the surrounding content.
