Lesson 1: Formula foundations

This course uses English function names and comma argument separators, as in Microsoft 365 for Windows. Some regional settings use semicolons. A formula starts with =; cell references identify the input cells and ranges.

Sample data: enter 12, 8, 10, and 10 in cells B2:B5. The examples below use that range.

References, operators, and core formulas

A relative reference such as A1 shifts when copied. An absolute reference such as $A$1 stays fixed. Mixed references $A1 and A$1 lock only the column or row. Press F4 while editing a reference to cycle through these forms.

Build and audit a formula

  1. Select the output cell and type =.
  2. Enter a function name, then select its arguments with the mouse or keyboard.
  3. Close the parenthesis and press Enter.
  4. Copy the formula down and check whether each reference should move or stay fixed.

Use Evaluate Formula to step through a complex expression. Use Trace Precedents to identify its inputs. Avoid hard-coded totals when a range formula can update automatically.
