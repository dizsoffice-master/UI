Lesson 1: Read data with SELECT

SQL describes the rows you want from a relational database. The examples use a table named orders with columns order_id, customer_id, order_date, and total. Put each clause on its own line so queries are easy to inspect.

Start by returning every column for a small number of rows, then select only the fields the task needs.

SELECT order_id, customer_id, total
FROM orders
ORDER BY order_date DESC
LIMIT 10;

Copy a starter query: SELECT order_id, total FROM orders ORDER BY order_date DESC LIMIT 10;

Logical query order

Although SELECT appears first, a useful mental model is FROM, WHERE, GROUP BY, HAVING, SELECT, ORDER BY, then LIMIT. This explains why a SELECT alias is not always available in WHERE.
