Chapter 1: HTML Foundations

Every webpage starts with a document skeleton. Learn how the HTML root, head, body, and metadata define the browser context.

What does html foundations mean?

Begin with the smallest working example, identify what each part does, and then extend it one step at a time. This makes it easier to spot errors and understand how the concept fits into a complete HTML project.

<html>
  <head>
    <title>My first page</title>
  </head>
  <body>
    <h1>Hello, world!</h1>
  </body>
</html>

How to Study HTML

Choose elements for their meaning, nest them in a clear document structure, and use descriptive attributes. Check that links and forms work with a keyboard and that images have useful alternative text. Practice each chapter with a small change of your own before moving to the next topic.
