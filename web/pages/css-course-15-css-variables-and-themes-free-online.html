What to know about CSS variables and themes in CSS

Variables centralize colors, spacing, and sizing so themes are easier to maintain across a project. This chapter explains the concept, demonstrates a practical example, and gives you a guided exercise.

How to use CSS variables and themes in CSS

Write a rule with a clear selector and declarations, then inspect the cascade in browser developer tools. Prefer reusable classes, responsive units, and visible focus styles.

Example: CSS variables and themes in CSS

Use this example as a starting point. Identify the part that controls the result, then adapt it to your own page or project.

:root { --primary: #2563eb; --space: 1rem; }
.card { background: var(--primary); }

Common questions about CSS variables and themes

When should I use CSS variables and themes?

Use this technique when it expresses the structure, styling, or behavior your page needs. Keep the implementation focused and test it with the surrounding content.

What should I practice next?
