Lesson 8: Define criteria precisely

Assume A2:A100 contains region, B2:B100 contains dates, C2:C100 contains sales rep, and D2:D100 contains amounts. Keep criteria ranges the same size as the sum range.

Sum sales for the West region: =SUMIF(A2:A100,"West",D2:D100)

Criteria tips and date ranges

Criteria such as ">=1000" are text expressions. For a comparison stored in another cell, join the operator and value, such as ">="&F2. For a month total, use a start date and an exclusive next-month bound with SUMIFS. In database functions, criteria headers must match database field names exactly.
