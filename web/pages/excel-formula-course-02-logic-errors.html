Lesson 2: Turn conditions into decisions

Logical functions return TRUE or FALSE, or choose a result based on a test. In the examples, A2 contains a score and B2 contains an order status.

Example: if A2 is 82, =IF(A2>=70,"Pass","Retry") returns Pass. Text results need quotation marks.

Logical and error formulas

Use exact comparisons and explicit fallback results. IFERROR catches every error, so reserve it for cases where a friendly fallback is meaningful; IFNA catches only #N/A.

Nested decisions and good error messages

Prefer IFS or SWITCH when many branches make nested IF difficult to audit. Use a deliberate final condition so unmatched values do not silently receive the wrong category.

  1. Test blank inputs before doing arithmetic.
  2. Return a meaningful label such as "Check quantity" instead of masking every problem as zero.
  3. Use IFNA for a lookup miss and let other errors remain visible during development.
