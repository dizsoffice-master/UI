Lesson 3: Text is data too

Imported CSV files, names, product codes, and addresses often contain inconsistent spacing or mixed formatting. These functions return text unless noted otherwise. In the examples, A2 contains " North-042 ".

Clean imported text: =TRIM(CLEAN(A2))

Split and rebuild a value

For older Excel, combine LEFT, MID, RIGHT, FIND, and LEN. In Microsoft 365, TEXTSPLIT can split a value across columns or rows; see Lesson 9 for dynamic-array formulas. Formatting numbers with TEXT creates text, so keep the original numeric value for calculations.

  1. Clean spaces and line breaks first.
  2. Find a delimiter rather than assuming a fixed position when source data varies.
  3. Check whether a result must remain numeric, especially dates and amounts.
