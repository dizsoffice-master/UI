Lesson 4: Excel stores dates as serial numbers

Dates are numbers formatted to look like calendar dates; times are fractions of a day. Subtracting two dates gives elapsed days. Use DATE to build dates from numeric year, month, and day values instead of joining date text.

If A2 is 2025-01-15 and B2 is 2025-02-01, =B2-A2 returns 17 days. Format the result as Number.

Dates that work across locales

Store true date values, not strings such as "01/02/25", which can mean different dates in different regions. Use number formats for display, and pass an explicit weekend code to the .INTL functions when Saturday/Sunday is not the weekend.
