Lesson 3: Summarize rows by group

Aggregates reduce many input rows to one output per group. In PostgreSQL, every selected expression must be grouped or aggregated.

SELECT customer_id, COUNT(*) AS order_count, SUM(total) AS lifetime_total
FROM orders
WHERE status = 'paid'
GROUP BY customer_id
HAVING SUM(total) >= 500
ORDER BY lifetime_total DESC;

WHERE versus HAVING

Use WHERE to filter source rows before groups are calculated. Use HAVING to filter results of aggregate expressions. Be cautious when grouping by timestamps: grouping by the exact timestamp may create one group per row; truncate to a date or reporting period where appropriate.
