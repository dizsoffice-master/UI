Lesson 2: Filter rows with WHERE

WHERE evaluates each row before grouping. Use parameters for user-provided values in applications; never construct SQL by concatenating untrusted input.

SELECT order_id, total
FROM orders
WHERE total >= 100
  AND order_date >= DATE '2025-01-01'
ORDER BY total DESC, order_id;

NULL and date-range rules

SQL uses three-valued logic: a comparison with NULL is unknown, not true or false. Use IS NULL or IS DISTINCT FROM. For timestamps, prefer half-open ranges such as created_at >= start_date AND created_at < next_date so all times on the final day are included safely.
