# Page Flow Reference

Line anchors refer to current source. The static site is `web/index.html` plus `web/pages/*.html`; every HTML document also has a same-basename JS companion. The hidden-ad files are fragments, not standalone content pages.

## Shared Render Flow

- Shared shell: [page-settings.js](assets/page-settings.js#L1) holds page navigation metadata. [site-partials.js](assets/site-partials.js#L409) inserts shared headers, navigation, footer, tool directory, and ad placements.
- Ads: [ad-settings.js](assets/ad-settings.js#L1) configures providers and slots. [adsense.js](assets/adsense.js#L133) initializes slots; the DOM-ready call is at [adsense.js](assets/adsense.js#L187).
- Generic tools: [online-tools.js](assets/online-tools.js#L4) defines tool data; [online-tools.js](assets/online-tools.js#L3070) renders the tool and guide; [online-tools.js](assets/online-tools.js#L3322) guards initialization; [online-tools.js](assets/online-tools.js#L3330) exposes the per-page initializer; [online-tools.js](assets/online-tools.js#L3338) provides the DOM-ready fallback.
- Document makers: [document-makers.js](assets/document-makers.js#L11) defines maker data; [document-makers.js](assets/document-makers.js#L152) renders the form and preview; [document-makers.js](assets/document-makers.js#L202) guards initialization; [document-makers.js](assets/document-makers.js#L210) exposes the per-page initializer; [document-makers.js](assets/document-makers.js#L218) provides the fallback.
- Shared CSS: [master.css](assets/master.css#L5) defines tokens, [master.css](assets/master.css#L170) styles shared wrappers, [master.css](assets/master.css#L745) styles tool guides, and [master.css](assets/master.css#L765) styles makers. [site-columns.css](assets/site-columns.css#L19) defines responsive columns.

## Flutter And API Flow

- Flutter starts at [main.dart](../lib/main.dart#L5). [app.dart](../lib/app.dart#L10) builds `MaterialApp`; route registrations are at [app.dart](../lib/app.dart#L18), with `/login` using `features/auth/LoginPage` and `/index` using `screens/IndexPage`. Platform-specific home selection is at [app.dart](../lib/app.dart#L22).
- The Flutter index is [screens/index_page.dart](../lib/screens/index_page.dart#L7). The `/login` feature screen is [features/auth/login_page.dart](../lib/features/auth/login_page.dart#L7), which navigates to [features/dashboard/dashboard_page.dart](../lib/features/dashboard/dashboard_page.dart#L5); the mobile home login is separately implemented in [screens/login_page.dart](../lib/screens/login_page.dart#L6).
- The offers API is [api/main.py](../api/main.py#L6): `/health` is at [api/main.py](../api/main.py#L20), and filtered offers are at [api/main.py](../api/main.py#L25). The web offers page currently filters its local demo array in [local-business-offers.js](pages/local-business-offers.js#L1); it does not call the API.
